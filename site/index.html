Self-hosted · end-to-end encrypted · plain Markdown

Write in Markdown. Your server only sees noise.

coolpsonotes is a notes app you run yourself. Notes are encrypted on your devices before they sync, so the server stores ciphertext and nothing else. Write in the browser with live collaboration, or keep your vaults as a folder of Markdown files and use your own editor.

What it is for

Private by design

Note text, titles, folder names, attachments and history are encrypted with keys that only your devices hold. Whoever runs the server, or breaks into it, gets ciphertext.

Made for working together

Share a vault with family or a team as editor or viewer, or share a single note. Everyone edits the same note at once, with live cursors and no lost changes, also after working offline.

Plain Markdown, your files

Notes are Markdown with wiki links, tags and embeds. Export a vault as .md files at any time, or keep it synced as a folder on your disk.

Use your own editor

The desktop client keeps your vaults as an ordinary folder of Markdown files, always up to date. Edit them in Obsidian, Neovim, VS Code or anything else. Changes sync both ways and merge with what others write in the web app at the same time.

The files are plain text on your machine. The server still only ever sees them encrypted, so coolpsonotes works as an end-to-end encrypted sync server for an Obsidian vault, with a web app and collaboration on top.

Set it up in a few minutes

$ coolpsonotes login --server https://notes.example.com
$ coolpsonotes sync --dir ~/Notes
syncing 2 vaults, watching ~/Notes
~/Notes/ Family/ Weekend trip.md Groceries.md Recipes/Pancakes.md assets/cabin.jpg Work/ Roadmap.md ← open in your editor

How it works

  1. Encrypt on your device

    Every change is encrypted in the browser or desktop client with the vault's key, before it leaves your device.

  2. Sync ciphertext

    The server orders and stores encrypted changes and passes them on live. It knows who is a member of a vault, not what anyone wrote.

  3. Decrypt for members

    Members' devices hold the vault key, wrapped to each person's own key. They decrypt and merge the changes locally.

Run it yourself

coolpsonotes is open source under the AGPL. You need a machine with Docker, a domain name and an OpenID Connect provider for sign-in. Caddy takes care of HTTPS.

Want to look around first? Development mode runs without a sign-in provider: open two browser tabs, sign in as two people and share a vault between them. Or run task demo for a server with users, shared vaults and linked notes already in it.

Self-hosting guide
$ git clone https://github.com/coolapso/coolpsonotes
$ cd coolpsonotes
$ cp .env.example .env  # domain, sign-in
$ docker compose up -d --build
